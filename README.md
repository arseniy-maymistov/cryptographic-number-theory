# Number-Theoretic Algorithms for Cryptography

Algorithm coursework on GCD methods, primality testing, integer factorization, and discrete logarithms, including performance observations.

## Overview

The reports study and compare classical number-theoretic algorithms used in cryptography. Topics include Euclidean GCD variants, probabilistic primality tests, Pollard factorization methods, the continued-fraction method, and discrete-logarithm algorithms.

## Topics and Features

- Euclidean, extended, binary, and truncated-remainder GCD algorithms
- Fermat, Solovay–Strassen, and Miller–Rabin primality tests
- Pollard rho and Pollard p−1 factorization methods
- Continued-fraction factorization (CFRAC)
- Pollard rho and Gelfond-style methods for discrete logarithms
- Discussion of runtime, iteration counts, and practical limits

## Technologies

Number theory, modular arithmetic, cryptographic algorithms, algorithmic complexity
